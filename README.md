# BreakLoop resource pack

Server resource pack for **BreakLoop** (Minecraft 1.21.11): menu backgrounds, logo, icons and boss bars.
Older 1.21.x clients load it too; the animated text colours need 1.21.11 or newer.

The server sends it automatically - you don't need to install it by hand.

Download: [BreakLoop.zip](https://github.com/xFayzeen/breakloop-resourcepack/raw/main/BreakLoop.zip)
